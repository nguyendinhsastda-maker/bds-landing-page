# 🏙️ Vinhomes Grand Park – Landing Page

Landing page giới thiệu dự án bất động sản **Vinhomes Grand Park** – Đô thị thông minh tại TP. Thủ Đức, TP. Hồ Chí Minh.

## 🚀 Demo

Mở file `index.html` trực tiếp trên trình duyệt hoặc deploy lên GitHub Pages.

## ✨ Tính năng

- **Responsive** – Tương thích mọi thiết bị (mobile, tablet, desktop)
- **Navbar thông minh** – Hiệu ứng scroll, hamburger menu trên mobile
- **Hero section** – Animation counter, stats, CTA buttons
- **Tổng quan dự án** – 4 thẻ nổi bật với hover effect
- **Tiện ích** – 6 tiện ích nội khu
- **Bảng giá căn hộ** – Studio, 2PN, 3PN
- **Vị trí** – Thông tin kết nối giao thông
- **Form liên hệ** – Validation + toast notification
- **Scroll animations** – Intersection Observer API
- **Không dùng framework** – Pure HTML, CSS, JS

## 📁 Cấu trúc

```
bds-landing-page/
├── index.html      # Trang chính
├── style.css       # Toàn bộ styles
├── script.js       # Tương tác & animations
└── README.md       # Tài liệu
```

## 🛠️ Chạy local

```bash
# Mở trực tiếp
open index.html

# Hoặc dùng live server
npx serve .
```

## 📦 Deploy GitHub Pages

1. Vào Settings → Pages
2. Chọn branch `main` → folder `/root`
3. Save – website sẽ live tại `https://<username>.github.io/bds-landing-page`
